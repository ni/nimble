Chat components are used to display a conversation with a chat bot or other
users. The components can collect input and display messages but the application
is responsible for managing the messages in the conversation.

Components include a chat message, a chat conversation, and a chat input.

## Usage

These components are part of [Spright](?path=/docs/spright-docs--docs). They can
be used in production applications but are not yet part of the core Nimble
library for reasons including:

1. the interaction and visual design are iterating rapidly
2. we are unsure if the components are sufficiently atomic or general purpose to
   belong in Nimble
3. the implementation has not yet prioritized Nimble requirements like
   accessibility and support for all frameworks

Tool names, input names, and values are rendered as text. Do not place executable markup, markdown, command output, or rich result content in tool-call attributes. Detailed results, approvals, live output, and interactive requests remain application-owned.

Arrays and objects must be JSON serialized into an input's `value`. A React or backend `arguments` object maps to one input child per named argument. Angular and Blazor consumers should likewise project child elements and bind primitive attributes; framework wrappers are not yet available.

## Accessibility

The tool summary uses a native disclosure button with `aria-expanded` and `aria-controls`. Status is always shown as text as well as an icon. Tool names and values remain selectable and wrap at narrow widths.
