## TanStack Charts

Add the `nimble-tanstack-chart` class to the element where you mount the graph, and copy this CSS into your application. It maps the palette and tooltip tokens without overriding TanStack's SVG label sizing. The styles follow Nimble theme changes without rebuilding the graph.

## Plotly

The OK FV helper reads Nimble tokens from a graph container attached to a browser document and returns a fresh [Plotly layout template](https://plotly.com/javascript/reference/layout/#layout-template). It sets common defaults for typography, colors, Cartesian axes, and hover labels. Set any trace- or subplot-specific styles in your figure. Use the helper with the Plotly instance your app already imports.

The examples keep the native toolbar visible and hide the Share button and Plotly logo.

```js
import { createNimblePlotlyTemplate } from '@ni/ok-components/dist/esm/fv/plotly-template';

function renderChart(chart, data, layout = {}, config = {}) {
    return Plotly.react(chart, data, {
        ...layout,
        template: layout.template ?? createNimblePlotlyTemplate(chart)
    }, config);
}
```

Call `renderChart` after mounting the graph container and again after your app switches themes. The helper doesn't observe theme changes. Plotly receives resolved values, so changing the CSS tokens alone won't redraw it. Explicit layout settings override the defaults; passing `layout.template` replaces the Nimble template.
