A split button that exposes a primary action and a secondary menu.

The outline, block, and ghost appearances use an inset divider and independent hover and keyboard-focus indicators for each action. An open menu highlights the toggle and aligns beneath it, with a width determined by the menu content.

Disabled block primary and accent variants retain their variant foreground color at 30% opacity.

Use the `start` and `end` slots for icons before and after the primary action label. These slots follow the text direction.

The `menu` slot supports a single slotted `nimble-menu`. Menu closing behavior is wired to that menu's `change` event.
