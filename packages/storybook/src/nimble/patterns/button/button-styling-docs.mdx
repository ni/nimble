### Appearances

Use `appearance` to choose visual emphasis: `ghost` (least), `outline`, or
`block` (most). For a group of actions, choose one prominent action and pair it
with ghost buttons. Do not mix outline and block buttons to create hierarchy.

#### Ghost Button

<StoryShowcase example={
        <div className="button-actions">
            <Button appearance="ghost">Ghost Button</Button>
            <Button appearance="ghost" content-hidden>
                <NimbleIconKey slot="start"></NimbleIconKey>
                Ghost Button
            </Button>
        </div>
    }>
        <h5>When to Use</h5>
        <ul>
            <li>Use ghost, the default appearance, for low-emphasis actions.</li>
            <li>
                Ensure the button is distinguishable from nearby text, tabs, and links.
            </li>
        </ul>
</StoryShowcase>

#### Outline Button

<StoryShowcase example={
        <div className="button-actions">
            <Button appearance="outline">Outline Button</Button>
            <Button appearance="outline" content-hidden>
                <NimbleIconKey slot="start"></NimbleIconKey>
                Outline Button
            </Button>
        </div>
    }>
        <h5>When to Use</h5>
        <ul>
            <li>
                Use outline when an action needs a visible boundary and more
                emphasis than a ghost button, without a filled background.
            </li>
        </ul>
</StoryShowcase>

#### Block Button

<StoryShowcase example={
        <div className="button-actions">
            <Button appearance="block">Block Button</Button>
            <Button appearance="block" content-hidden>
                <NimbleIconKey slot="start"></NimbleIconKey>
                Block Button
            </Button>
        </div>
    }>
        <h5>When to Use</h5>
        <ul>
            <li>
                Use block for the strongest emphasis, such as an important
                action that could otherwise be overlooked in a busy layout.
            </li>
        </ul>
</StoryShowcase>

### Appearance Variants

Use `appearance-variant` to change the color treatment of an outline or block
button: `accent` uses the brand accent color, while `primary` provides an
alternative when that color would convey the wrong meaning. Variants do not
apply to ghost buttons.

#### Accent Button

<StoryShowcase example={
        <div className="button-stack">
            <div className="button-row">
                <Button appearance="ghost">Ghost</Button>
                <Button appearance="ghost">Ghost</Button>
                <Button appearance="outline" appearance-variant="accent">Outline Accent</Button>
            </div>
            <hr/>
            <div className="button-row">
                <Button appearance="ghost">Ghost</Button>
                <Button appearance="ghost">Ghost</Button>
                <Button appearance="block" appearance-variant="accent">Block Accent</Button>
            </div>
        </div>
    }>
        <h5>When to Use</h5>
        <ul>
            <li>
                Choose accent when brand color is appropriate for the action.
                Avoid it when green could misleadingly imply success or safety.
                Use a clear label rather than relying on color alone.
            </li>
        </ul>
</StoryShowcase>

#### Primary Button

<StoryShowcase example={
        <div className="button-stack">
            <div className="button-row">
                <Button appearance="ghost">Ghost</Button>
                <Button appearance="ghost">Ghost</Button>
                <Button appearance="outline" appearance-variant="primary">Outline Primary</Button>
            </div>
            <hr/>
            <div className="button-row">
                <Button appearance="ghost">Ghost</Button>
                <Button appearance="ghost">Ghost</Button>
                <Button appearance="block" appearance-variant="primary">Block Primary</Button>
            </div>
        </div>
    }>
        <h5>When to Use</h5>
        <ul>
            <li>
                Choose primary when the action needs emphasis without the
                accent color, for example when green would imply a positive
                outcome for a destructive action.
            </li>
        </ul>
</StoryShowcase>
