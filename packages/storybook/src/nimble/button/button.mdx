## Overview

Use a button for an action ([W3C pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/)).
Use <Tag name={anchorButtonTag} /> for navigation.

## Action hierarchy

Choose one prominent action and keep secondary actions low-emphasis.

<NimbleThemeProvider theme={theme}>
	<div style={{ display: 'flex', flexWrap: 'wrap', gap: '16px', alignItems: 'center' }}>
		<NimbleButton appearance="ghost">Cancel</NimbleButton>
		<NimbleButton appearance="block">Save changes</NimbleButton>
	</div>
</NimbleThemeProvider>

```html
<nimble-button appearance="ghost">Cancel</nimble-button>
<nimble-button appearance="block">Save changes</nimble-button>
```

## Choose an appearance

`appearance` controls visual emphasis. The default is `outline`.

<NimbleThemeProvider theme={theme}>
	<div style={{ display: 'flex', flexWrap: 'wrap', gap: '16px', alignItems: 'center' }}>
		<NimbleButton appearance="ghost">Ghost</NimbleButton>
		<NimbleButton appearance="outline">Outline</NimbleButton>
		<NimbleButton appearance="block">Block</NimbleButton>
	</div>
</NimbleThemeProvider>

| Need | Appearance | Guidance |
| --- | --- | --- |
| Low emphasis | `ghost` | Secondary actions |
| Standard emphasis with a visible boundary | `outline` | Most actions; default |
| Extra emphasis | `block` | One important action that should stand out, especially in a busy layout |

Buttons are 32px tall.

Choose `outline` or `block` based on how much the action needs to stand out,
not simply because it is primary. Use one block button at most in a group; pair
it with ghost buttons rather than mixing outline and block to create hierarchy.

`appearance-variant` changes the color of outline and block buttons. Choose
`accent` when brand color suits the action; choose `primary` when green could
imply the wrong meaning, such as a destructive action. Variants do not affect
ghost buttons, and accent is unavailable in the color theme.

<NimbleThemeProvider theme={theme}>
	<div style={{ display: 'flex', flexWrap: 'wrap', gap: '16px', alignItems: 'center' }}>
		<NimbleButton appearance="block" appearanceVariant="accent">Create</NimbleButton>
		<NimbleButton appearance="block" appearanceVariant="primary">Delete</NimbleButton>
	</div>
</NimbleThemeProvider>

## Add an icon when it helps

Prefer a visible label. Use an icon-only button when space is limited and its
action is recognizable. Keep text content for its accessible name and provide
a tooltip with `title`.

<NimbleThemeProvider theme={theme}>
	<div style={{ display: 'flex', flexWrap: 'wrap', gap: '16px', alignItems: 'center' }}>
		<NimbleButton appearance="outline">
			<NimbleIconKey slot="start" />
			Refresh
		</NimbleButton>
		<NimbleButton appearance="ghost" contentHidden title="Refresh">
			<NimbleIconKey slot="start" />
			Refresh
		</NimbleButton>
	</div>
</NimbleThemeProvider>

```html
<nimble-button appearance="outline">
	<nimble-icon-key slot="start"></nimble-icon-key>
	Refresh
</nimble-button>

<nimble-button appearance="ghost" content-hidden title="Refresh">
	<nimble-icon-key slot="start"></nimble-icon-key>
	Refresh
</nimble-button>
```

`content-hidden` hides the text and end icon, leaving the start icon visible.
Tab and Shift+Tab move focus; Enter and Space activate the button. Preserve
these built-in keyboard behaviors.
